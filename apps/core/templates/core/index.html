Nuestras actividades

Tres disciplinas, un mismo objetivo

Trabajamos el cuerpo de manera integral. Cada actividad está diseñada para la rehabilitación y el bienestar, sin importar tu edad ni condición física.

Tren Superior

Rehabilitación
de Tren Superior

Trabajamos hombros, brazos, pecho y espalda alta. Ideal para recuperarse de lesiones de cuello, columna cervical, codo o muñeca.

Zona Media

Rehabilitación
de Zona Media

Fortalecemos el core y la columna lumbar. Enfocado en el alivio de dolor lumbar, problemas posturales y recuperación abdominal.

Tren Inferior

Rehabilitación
de Tren Inferior

Rodillas, caderas, tobillos y musculatura de piernas. Perfecta para recuperar movilidad, fuerza y estabilidad después de lesiones.

Cómo funciona

Reservar es muy sencillo

Podés explorar todas las clases disponibles sin tener cuenta. Para reservar, solo necesitás registrarte.

1
